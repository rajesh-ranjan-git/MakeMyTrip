## Project Overview

MakeMyTrip-Clone is a single-page static replica of the MakeMyTrip.com homepage. It recreates the header, search/booking widgets, and promotional sections using only HTML and CSS, with no backend or JavaScript logic involved.

## Features

- **Landing Page Layout:** Recreation of MakeMyTrip's homepage structure (header, nav bar, booking widgets, promo sections).
- **Static Styling:** Pure CSS layout for the homepage sections.
- **Static Assets:** Local images used to mirror the original imagery.

## Tech Stack

- **Frontend:** HTML5, CSS3

## Folder Structure

```bash
MakeMyTrip/
├── images/        # Static images used across the page
├── index.html     # Main landing page markup
└── style.css      # Page styling
```

## Installation Guide

### Prerequisites

- A modern web browser
- (Optional) A local static server such as VS Code's "Live Server" extension

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/rajesh-ranjan-git/MakeMyTrip.git
   cd MakeMyTrip
   ```

2. Open `index.html` directly in your browser, or serve the folder with a local static server:

   ```bash
   npx serve .
   ```

## Usage Instructions

1. Open the page in your browser to view the recreated MakeMyTrip landing page.
2. Scroll through the header, booking widget, and promotional sections to see the layout.
